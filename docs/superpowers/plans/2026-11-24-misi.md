# Misi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Selalu ada 3 misi aktif yang berlaku di Petualangan dan Tanpa Batas. Progresnya berjalan dari kejadian di
game, dan misi yang selesai memberi koin di akhir run lalu diganti misi baru. Misi tampil di menu, layar jeda, dan
layar hasil/selesai.

**Architecture:** Templat misi adalah data (`Missions`). Status misi (aktif, progres, `mission_seq`) disimpan di
autoload `Game`. `game.gd` melaporkan kejadian ke `Game.mission_event(kind, amount)` dan memanggil
`Game.settle_missions()` di akhir run. UI memakai satu pembuat baris misi `UIKit.mission_row`.

**Tech Stack:** Godot 4.7.2, GDScript bertipe.

**Spec:** `docs/superpowers/specs/2026-11-24-petualangan-design.md` (bagian "Misi").

**Butuh:** langkah Petualangan (`2026-11-24-peta-petualangan.md`) sudah di-merge, karena kind `stars` dan `level_clean` memakai level.

## Status

- Selesai (`feat/misi`).

## Global Constraints
- 3 misi aktif, dan kind-nya tidak boleh sama.
- Templat dan hadiah sesuai tabel spec (skim, coins, pass, pass_ombak, pass_layangan, pass_hutan, stars, endless_island, level_clean).
- Progres dijumlahkan lintas run, kecuali `endless_island` (maksimum per run).
- Hadiah diberikan sekali, di akhir run (layar hasil/selesai atau keluar lewat jeda). Teks "Selesai! +N".
- Misi untuk pulau yang belum ada di `Levels.READY_ISLANDS` tidak pernah muncul.
- Teks bahasa Indonesia, tanpa simbol di luar Fredoka. Tes pakai `--nosave`.

## Review Focus
- Save lama (tanpa `missions`) → langsung mendapat 3 misi awal yang valid → tes Task 1.
- Keluar lewat jeda ("Menu") di tengah run tetap menghitung progres run itu dan memberi hadiah → tes Task 2.
- Lanjut via iklan tidak menghitung kejadian dua kali (mis. koin run sebelum dan sesudah Lanjut) → tes Task 2.
- Misi `endless_island` tidak maju di mode level → tes Task 2.
- Semua templat habis terpakai → urutan berputar dari awal tanpa error → tes Task 1.
